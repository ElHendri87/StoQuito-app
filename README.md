# StoQuito 1.0.0

StoQuito es una aplicación de inventario para Windows 10 y 11 de 64 bits. Su descarga, instalación y uso son gratuitos, también para gestionar un pequeño negocio.

## Descargar

Abra la [última versión publicada](https://github.com/ElHendri87/StoQuito-app/releases/latest) y descargue estos dos archivos de la sección **Assets**:

1. `StoQuito-Setup-1.0.0.exe` — instalador de la aplicación.
2. `GUIA_DE_USO.pdf` — manual paso a paso para Administrador, Operador y Consulta.

No descargue los archivos automáticos **Source code (zip)** o **Source code (tar.gz)** para instalar la aplicación: no son el instalador. El programa incluye .NET y no requiere instalarlo por separado.

Al instalar, lea la licencia que aparece en el asistente. El instalador no está firmado digitalmente, por lo que Windows puede mostrar un aviso de editor desconocido.
